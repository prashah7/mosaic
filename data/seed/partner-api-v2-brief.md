# Partner API v2 Migration — initiative brief

## Outcome

Migrate strategic partners from API v1 to v2 without breaking order synchronization or exceeding the support capacity reserved for Enterprise SSO.

## Q3 success metrics

- Three strategic partners complete v2 migration by September 20.
- API v1 deprecation communication is sent with a tested rollback path.
- Migration-related support tickets stay below five per week.

## Constraint

Support has one shared escalation rotation for Enterprise SSO and Partner API migration. A high-volume API migration cannot overlap the first SSO pilot expansion without explicit Support approval.
